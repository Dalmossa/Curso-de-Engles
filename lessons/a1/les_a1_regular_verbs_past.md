## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **regular verb** | verbo regular | *segue regra previsível* |
| **past tense** | tempo passado | *ação concluída* |
| **-ed ending** | terminação -ed | *marca do passado* |
| **work → worked** | trabalhar → trabalhou | *verbo regular* |
| **play → played** | jogar → jogou | *verbo regular* |
| **want → wanted** | querer → quis | *verbo regular* |
| **need → needed** | precisar → precisou | *verbo regular* |
| **-d ending** | terminação -d | *verbo terminado em e* |
| **live → lived** | morar → morou | *verbo terminado em e* |
| **-ied ending** | terminação -ied | *verbo terminado em y* |
| **study → studied** | estudar → estudou | *y → ied* |
| **pronunciation** | pronúncia | *som do -ed* |
| **/t/ sound** | som /t/ | *worked, watched* |
| **/d/ sound** | som /d/ | *played, lived* |
| **/ɪd/ sound** | som /ɪd/ | *wanted, needed* |

### Mini-texto (áudio: `deferred_render`)

> "**Regular verbs** add **-ed** for **past tense**: **work → worked**, **play → played**, **want → wanted**."
>
> "**-d ending**: verbs ending in **e** add only **-d**: **live → lived**, **love → loved**."
>
> "**-ied ending**: verbs ending in **y** change to **-ied**: **study → studied**, **try → tried**."
>
> "**Pronunciation**: **/t/** (worked), **/d/** (played), **/ɪd/** (wanted)."

## FASE 3 — Output Task [4 min]

### Speaking: Yesterday Game (pares)
**Talk about yesterday** using past tense verbs.

**Example:**
> A: "What did you do yesterday?"
> B: "I **worked**, **played** soccer, and **watched** TV."
> A: "Did you **study**?"
> B: "Yes, I **studied** English."

**Practice with**: work, play, watch, study, want, need, live, love, try.
