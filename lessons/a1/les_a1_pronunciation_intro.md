## FASE 1 — Input Contextualizado (i+1) [4 min]

### Cenário: alinhamento rápido antes da daily

> **Bruno (software engineer):** "Hi team. I think the script for the health check is ready."
>
> **Ana (QA engineer):** "Great. Can you run it three times and share the report?"
>
> **Bruno:** "Sure. Right after this call, I will start the screen share and help with the release."

### Glossário contrastivo (pt-BR ↔ en-US)

| Inglês (en-US) | Português (pt-BR) | Nota de uso em TI |
|---|---|---|
| **think** | pensar/achar | O *th* inicial é um som dental (língua entre os dentes), não /t/ nem /f/. |
| **three** | três | Mesmo som de *think*: *th* surdo /θ/. |
| **health** | saúde | Em *health check*, o *th* final também é /θ/. |
| **help** | ajudar | O *h* inicial é aspirado em inglês; não é mudo como em muitas palavras do pt-BR. |
| **right** | certo/correto | Em inglês americano, o *r* tem a língua curvada/recuada, sem vibração forte. |
| **report** | relatório/reportar | Palavra comum em reuniões: atenção ao *r* inicial e ao ritmo. |
| **script** | script/roteiro | Grupo *scr-* exige pronunciar o /s/ inicial sem acrescentar vogal antes. |
| **screen** | tela | Grupo *scr-*; evite "iscreen". |
| **start** | começar/iniciar | Grupo *st-*; evite "estart". |

### Tabela de armadilhas comuns (falantes de pt-BR)

| Armadilha (pt-BR → forma inadequada) | Forma alvo em en-US | Por quê? |
|---|---|---|
| Vogal epentética antes de grupo com *s*: "escript", "iscreen", "estart" | **script**, **screen**, **start** | Em inglês, o /s/ inicial de *s + consoante* é pronunciado diretamente, sem vogal de apoio. |
| *TH* pronunciado como /t/, /d/, /f/ ou /s/: "tink", "tree", "fink" para *think/three* | **think** /θɪŋk/, **three** /θriː/ | O som *th* surdo exige a língua entre os dentes e saída de ar sem vibração das cordas vocais. |
| *H* inicial omitido: "elp" para *help*, "ealth" para *health* | **help**, **health** | O *h* inicial em inglês é um sopro leve; omiti-lo muda a palavra percebida. |
| *R* forte ou vibrado como no pt-BR: "rreport" muito enrolado | **right**, **report** (aproximação em en-US) | O *r* do inglês americano não vibra na ponta da língua como o "r" forte do português. |
| Troca em par mínimo: *tree* no lugar de *three* | **three** (três) ≠ **tree** (árvore) | Um único som diferente muda o significado; treinar pares mínimos melhora a discriminação. |

## FASE 2 — Prática Guiada [5 min]

### Exercício 1 — Identificação do som-alvo

Associe cada palavra ao foco principal de pronúncia:

| Palavra | Foco |
|---|---|
| **think** | a. TH surdo /θ/ (língua entre os dentes) |
| **help** | b. H inicial aspirado |
| **report** | c. R em inglês americano |
| **script** | d. Grupo S+consoante sem vogal epentética |

**Key:** think → a, help → b, report → c, script → d.
**Chave:** think → a, help → b, report → c, script → d.

### Exercício 2 — Transformação L1 → L2 (forma oral clara)

Reescreva mentalmente como você diria em inglês, evitando a armadilha indicada:

| Intenção em pt-BR | Armadilha comum | Forma-alvo em en-US |
|---|---|---|
| "Eu acho que o script está pronto." | "eu tinco / eu escript" | "I **think** the **script** is ready." |
| "Rode três testes e envie o relatório." | "três" como /tri/, "relatório" com R vibrado forte | "Run **three** tests and send the **report**." |
| "Preciso de ajuda com a tela." | "elp" / "iscreen" | "I need **help** with the **screen**." |

### Exercício 3 — Discriminação de pares mínimos

Escolha a palavra que completa corretamente cada frase técnica:

1. "Please open issue number ____." (**three** / tree) → **three**
2. "We need to ____ the new engineer." (**help** / elp) → **help**
3. "I will ____ the bug now." (**report** / deport) → **report** (contexto: relatar) / foco no /r/ inicial limpo
4. "Check the deployment ____ before the release." (**script** / escript) → **script**

## FASE 3 — Tarefa de Produção (Output & Pronúncia) [4 min]

### 5 sentenças-alvo (leia em voz corrida)

I think the script is ready for the health check. Please run three tests right after the standup. I need help with the report on this screen. Can you start the review and share the results? Thank you for your help with the release today.

### Dicas articulatórias para brasileiros

- **TH surdo /θ/ em *think, three, health, thank***: coloque a ponta da língua levemente entre os dentes e deixe o ar passar sem vibrar as cordas vocais. Evite substituir por /t/, /f/ ou /s/.
- **H inicial em *help, health***: produza um sopro curto antes da vogal, como uma expiração leve. Não omita o som.
- **R em *right, report, release, results, review, run***: no inglês americano, curve levemente a língua para trás sem encostar no céu da boca e sem vibrar; evite o "r" forte do início de palavra em pt-BR.
- **Grupos com S+consoante em *script, screen, start, standup***: comece diretamente pelo /s/. Não insira "e" ou "i" antes (*escript*, *iscreen*, *estart*).
- **Ritmo**: leia as frases em blocos naturais (ex.: "I think the script | is ready | for the health check") para evitar pausas que geram vogais extras.

### Prompt de produção (oral)

Grave um áudio curto (45–60 segundos) simulando um aviso técnico para seu time. Diga: o que você acha que está pronto (*think*), quantos testes vai rodar (*three*), que precisa de ajuda com o relatório na tela (*help, report, screen*) e quando vai iniciar (*start*). Use pelo menos **4 palavras-alvo** da lição.

   D) report / reports  
   **Key:** B
   **Chave:** B

   B) **colocar a língua entre os dentes e soltar o ar sem voz**  
   C) omitir o primeiro som e começar pela vogal  
   D) acrescentar "i" antes da palavra
