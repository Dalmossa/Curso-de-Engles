## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Minimal pairs** are:
| Slot | Value |
|------|-------|
| A | Words with same meaning |
| B | **Words differing in one sound (three/tree)** |
| C | Words with same spelling |
| D | Words with same pronunciation |
**Key:** B
**br_pt_form:** "par mínimo / palavras que diferem em 1 som"

### Item 2 — Vocabulary (Matching)
Match the sound to its description:
| Sound | Description |
|-------|-------------|
| **TH (voiceless)** | a. three, think, thank |
| **TH (voiced)** | b. this, that, mother |
| **H** | c. house, hello, help |
| **R** | d. red, right, room |
**Key:** TH (voiceless)→a, TH (voiced)→b, H→c, R→d
**br_pt_form:** "TH surdo", "TH sonoro", "H", "R"

### Item 3 — Grammar: Articles with sounds (fill-in-blank)
Complete with **a / an**:
"______ H sound, ______ TH sound, ______ R sound, ______ S+C cluster."
**Key:** an / a / an / an
**br_pt_form:** "um / uma"

---

## FASE 3 — Output Task [4 min]

### Speaking: Minimal Pair Practice (individual)
**Practice these minimal pairs** (listen and repeat):

1. **TH**: three/tree, think/sink, thank/tank
2. **H**: house/horse, hit/heat, hall/hole
3. **R**: red/led, right/light, road/load
4. **S+C**: sip/ship, sock/shock, sign/shine

**Record yourself** and compare with the audio. Focus on **tongue** position for TH.
