## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **false cognate** | falso cognato | *parece igual, significa outro* |
| **actually** | na verdade | *não "atualmente"* |
| **pretend** | fingir | *não "pretender"* |
| **library** | biblioteca | *não "livraria"* |
| **parent** | pai/mãe | *não "parente"* |
| **push** | empurrar | *não "puxar"* |
| **pull** | puxar | *não "empurrar"* |
| **exit** | saída | *não "êxito"* |
| **success** | sucesso | *não "sucesso" (falso amigo de "sucesso" em PT)* |
| **career** | carreira | *não "carro"* |
| **data** | dados | *não "data" (dia/mês/ano)* |
| **notice** | notar / aviso | *não "notícia"* |

### Mini-texto (áudio: `deferred_render`)

> "**False cognates** trap Brazilian learners. **Actually** = *na verdade* (not *atualmente*). **Pretend** = *fingir* (not *pretender*)."
>
> "**Library** = *biblioteca* (not *livraria*). **Parent** = *pai/mãe* (not *parente*). **Push** = *empurrar* (not *puxar*)."
>
> "**Exit** = *saída* (not *êxito*). **Career** = *carreira* (not *carro*). **Data** = *dados* (not *data*)."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Actually** means:
| Slot | Value |
|------|-------|
| A | Atualmente |
| B | **Na verdade** |
| C | Atualmente mesmo |
| D | Actual |
**Key:** B
**br_pt_form:** "na verdade / não atualmente"

### Item 2 — Vocabulary (Matching)
Match the false cognate to its real meaning:
| Word | Real meaning |
|------|--------------|
| **Pretend** | a. Fingir |
| **Library** | b. Biblioteca |
| **Parent** | c. Pai/Mãe |
| **Exit** | d. Saída |
**Key:** Pretend→a, Library→b, Parent→c, Exit→d
**br_pt_form:** "fingir", "biblioteca", "pai/mãe", "saída"

### Item 3 — Grammar: Present simple with false cognates (fill-in-blank)
Complete with **correct verb form**:
"I ______ (actually/am) from Brazil. She ______ (pretend/is) tired. They ______ (library/study) at the library."
**Key:** am / is / study
**br_pt_form:** "sou / está / estudam"

---

## FASE 3 — Output Task [4 min]

### Speaking: False Cognate Correction (pares)
**Correct these sentences:**

1. "I am actually from Brazil." (I am **actually** from Brazil → I am **currently** from Brazil? No! **Actually** = **na verdade**)
2. "I pretend to be a doctor." (I **pretend** to be a doctor → I **fingir** to be a doctor? No! **Pretend** = **fingir**)
3. "I work in a library." (I work in a **library** → I work in a **biblioteca**? No! **Library** = **biblioteca**)

**Create 4 more false cognate sentences** and correct them.
