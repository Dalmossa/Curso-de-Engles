## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **I don't understand** | eu não entendo | *não compreender* |
| **Can you repeat that?** | pode repetir? | *pedir repetição* |
| **Can you speak slowly?** | pode falar devagar? | *pedir para falar lento* |
| **What does ... mean?** | o que ... significa? | *perguntar significado* |
| **How do you say ... in English?** | como se diz ... em inglês? | *pedir tradução* |
| **Where is the bathroom?** | onde fica o banheiro? | *perguntar local* |
| **How much is this?** | quanto custa isto? | *perguntar preço* |
| **I would like...** | eu gostaria de... | *pedir algo* |
| **the bill, please** | a conta, por favor | *pedir conta* |
| **help!** | socorro! | *pedir ajuda* |
| **I need help** | preciso de ajuda | *precisar de assistência* |
| **call the police** | chame a polícia | *emergência* |

### Mini-texto (áudio: `deferred_render`)

> A: **I don't understand. Can you repeat that?**
> B: Sure! **Can you speak slowly?**
> A: Yes, please. **What does "expensive" mean?**
> B: It means "caro". **How do you say "banheiro" in English?**
> A: "Bathroom". **Where is the bathroom?**
> B: Over there. **How much is this?**
> A: It's $10. **I would like this, please.**
> B: OK. **The bill, please.**
> A: **Help! I need help!**

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Can you repeat that?** is used when:
| Slot | Value |
|------|-------|
| A | You understand everything |
| B | **You didn't understand and want repetition** |
| C | You want to leave |
| D | You want to speak |
**Key:** B
**br_pt_form:** "pode repetir? / não entendi"

### Item 2 — Vocabulary (Matching)
Match the survival phrase to its situation:
| Phrase | Situation |
|--------|-----------|
| **I don't understand** | a. Didn't comprehend |
| **How much is this?** | b. Asking price |
| **Where is the bathroom?** | c. Asking location |
| **Help!** | d. Emergency |
**Key:** I don't understand→a, How much is this?→b, Where is the bathroom?→c, Help!→d
**br_pt_form:** "não entendo", "quanto custa?", "onde fica o banheiro?", "socorro!"

### Item 3 — Grammar: Can for requests (fill-in-blank)
Complete with **can**:
"______ you repeat? ______ you speak slowly? ______ I have the bill?"
**Key:** Can / Can / Can
**br_pt_form:** "Pode / Pode / Posso"

## FASE 3 — Output Task [4 min]

### Speaking: Survival Situations (pares)
**Practice these scenarios:**

1. **Restaurant**: Order food, ask for bill
2. **Shop**: Ask price, say "I would like this"
3. **Street**: Ask where bathroom is
4. **Class**: Say "I don't understand", "Can you repeat?"
5. **Emergency**: Say "Help!", "Call the police"

**Create a short dialogue** for each scenario using the vocabulary.

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**I would like** is used to:
| Slot | Value |
|------|-------|
| A | Refuse something |
| B | **Request something politely** |
| C | Apologize |
| D | Say goodbye |
**Key:** B
**br_pt_form:** "eu gostaria de / pedir educadamente"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **can** request:
| Slot | Value |
|------|-------|
| A | **Can** you repeat? |
| B | **Do** you repeat? |
| C | **Are** you repeat? |
| D | **Is** you repeat? |
**Key:** A
**br_pt_form:** "Pode repetir?"
