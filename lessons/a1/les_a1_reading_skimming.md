### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **skimming** | skimming / leitura rápida | *ideia geral do texto* |
| **scanning** | scanning / leitura direcionada | *informação específica* |
| **main idea** | ideia principal | *ponto central* |
| **title** | título | *cabeçalho do texto* |
| **first sentence** | primeira frase | *introdução* |
| **last sentence** | última frase | *conclusão* |
| **keyword** | palavra-chave | *termo importante* |
| **specific information** | informação específica | *detalhe procurado* |

| **read carefully** | ler com atenção | *leitura detalhada* |

| **context** | contexto | *situação do texto* |
| **guess** | adivinhar / inferir | *deduzir significado* |

### Mini-texto (áudio: `deferred_render`)

> "**Skimming**: read **quickly** for **main idea**. Read **title**, **first sentence**, **last sentence**."
>
> "**Scanning**: read for **specific information**. Look for **keywords** like names, dates, numbers."
>
> "**Example**: Skim a news article → main idea. Scan for a date → specific information."
>
> "**Context** helps **guess** meaning of unknown words."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Skimming** means:
| Slot | Value |
|------|-------|
| A | Reading every word carefully |
| B | **Reading quickly for main idea** |
| C | Translating |
| D | Memorizing |
**Key:** B
**br_pt_form:** "skimming / leitura rápida para ideia geral"

### Item 2 — Vocabulary (Matching)
Match the reading skill to its purpose:
| Skill | Purpose |
|-------|---------|
| **Skimming** | a. Main idea |
| **Scanning** | b. Specific information |
| **Title** | c. Text heading |
| **Keyword** | d. Important term |
**Key:** Skimming→a, Scanning→b, Title→c, Keyword→d
**br_pt_form:** "skimming", "scanning", "título", "palavra-chave"

### Item 3 — Grammar: Imperatives for reading strategies (fill-in-blank)
Complete with **imperative verbs**:
"______ (read) the title. ______ (skim) for main idea. ______ (scan) for dates. ______ (guess) from context."
**Key:** Read / Skim / Scan / Guess
**br_pt_form:** "Leia / Faça skimming / Faça scanning / Inferir"

## FASE 3 — Output Task [4 min]

### Reading: Skim & Scan Practice (individual)
**Read this short text:**

> "Tech Company Announces New Product. Yesterday, XYZ Corp launched a new smartphone. The device features a 6.5-inch screen, 128GB storage, and costs $699. It will be available in stores next month."

**Tasks:**
1. **Skim**: What is the main idea? (1 sentence)
2. **Scan**: What is the screen size? How much does it cost? When is it available?
3. **Guess**: What does "device" mean from context?
