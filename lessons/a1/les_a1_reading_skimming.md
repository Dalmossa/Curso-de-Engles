# Lesson: Skimming & Scanning

**Module:** `mod_a1_comm_basic`

**Reuse basis:** `authored_material`
**Source:** Original authored material for Brazilian software engineers (pt-BR → en-US).
**Estimated time:** 15 min

---

## FASE 1 — Input Contextualizado (i+1) [4 min]

### Cenário: três minutos antes da daily reunião

> **Bruno (QA engineer):** "You look busy. Do you need to read the incident note before standup?"
>
> **Ana (product support):** "Yes, and it is long. I only have three minutes."
>
> **Bruno:** "Don't read every word. First, skim the title and the first sentence for the main idea."
>
> **Ana:** "And if I need the deploy time?"
>
> **Bruno:** "Scan the note for the time and the build number. Read slowly only at the end."
>
> **Ana:** "So I skim for the big picture and scan for one answer."

### Glossário contrastivo (pt-BR ↔ en-US)

| Inglês (en-US) | Português (pt-BR) | Nota de uso prático |
|---|---|---|
| **to skim** | fazer uma leitura rápida | Ler rápido para a ideia geral; o objeto vem logo depois (*skim the note*). |
| **to scan** | fazer uma busca direcionada | Ler procurando **um** detalhe específico (*scan for the date*). |
| **main idea** | ideia principal | O ponto central do texto; normalmente está no título e na primeira frase. |
| **title** | título | A primeira linha de qualquer nota, ticket ou release note. |
| **heading** | cabeçalho / subtítulo | Separa as partes de um texto mais longo. |
| **first sentence** | primeira frase | Costuma apresentar o assunto do parágrafo. |
| **last sentence** | última frase | Muitas vezes resume ou conclui o parágrafo. |
| **keyword** | palavra-chave | Nome, data, número ou termo técnico que você procura. |
| **to guess from context** | inferir pelo contexto | Descobrir o significado de uma palavra desconhecida sem parar a leitura. |
| **to read carefully** | ler com atenção | Leitura lenta e detalhada, só para o trecho que importa. |

### Tabela de armadilhas comuns (falantes de pt-BR)

| Armadilha (pt-BR → forma inadequada) | Forma natural em en-US | Por quê? |
|---|---|---|
| "I need **scan** the note." | "I need **to scan** the note." | Depois de *need*, o verbo usa *to* + forma base: *need to scan*. |
| "Read the title and the first **phrase**." | "Read the title and the first **sentence**." | *Sentence* é a frase com verbo; *phrase* é um grupo curto de palavras sem verbo. |
| "Skim the note **of** the main idea." | "Skim the note **for** the main idea." | A preposição que acompanha *skim* e *scan* aqui é *for*. |
| "Read the note **in voice alta**." | "Read the note **aloud**." | *Aloud* já significa "em voz alta"; não se traduz *in voice alta*. |
| "Make one **scanning** in the text." | "**Scan** the text." | Em inglês a ação é o verbo *scan*; *scanning* soa como substantivo técnico isolado. |

## FASE 2 — Prática Guiada [5 min]

### Exercício 1 — Reconhecimento (skimming)

Qual frase descreve **skimming**?

| Opção | Frase |
|---|---|
| A | "Read every word slowly." |
| B | **"Read the title and the first sentence quickly."** |
| C | "Translate the note into Portuguese." |
| D | "Count the pages and the lines." |

**Key:** B
**Chave:** B — *Skimming* é leitura rápida para a ideia geral: título, primeira frase e últimas frases primeiro. *Count the pages* e *translate* são tarefas diferentes.

### Exercício 2 — Estratégia ↔ propósito (L1 → L2)

Escreva a ação em inglês para cada objetivo:

| Objetivo (pt-BR) | Ação esperada (en-US) |
|---|---|
| "Quero a ideia geral da nota em dez segundos." | "Skim the title and the first sentence." |
| "Quero só o horário do deploy." | "Scan the note for the time." |
| "Não conheço a palavra *cache*." | "Guess the meaning from the context." |
| "O detalhe é crítico para o ticket." | "Read that part carefully." |

**Key:** Skim the title and the first sentence. / Scan the note for the time. / Guess the meaning from the context. / Read that part carefully.
**Chave:** Skim the title and the first sentence. / Scan the note for the time. / Guess the meaning from the context. / Read that part carefully.

### Exercício 3 — Instruções com o verbo na forma base

Complete as instruções de leitura com a forma correta do verbo:

1. "____ (skim) the release note first." → **Skim**
2. "____ (scan) the note for the build number." → **Scan**
3. "____ (read) carefully only after you find the part." → **Read**
4. "____ (guess) the new words from the context." → **Guess**

**Key:** 1) Skim; 2) Scan; 3) Read; 4) Guess.
**Chave:** 1) Skim; 2) Scan; 3) Read; 4) Guess.

## FASE 3 — Tarefa de Produção (Output & Pronúncia) [4 min]

### 5 sentenças-alvo (leia em voz corrida)

First, skim the title and the first sentence to get the main idea. Then scan the same note for the date and the number you need. Read carefully only when the detail is important for your task. Guess the unknown words from the context and keep reading. Skimming is fast, and scanning is for one specific answer.

### Foco articulatório para falantes de pt-BR

- **/iː/ vs /ɪ/ em *cheap* × *chip***: alongue o som de *cheap* (/iː/, "ii") e mantenha *chip* curto (/ɪ/, "i"); em pt-BR os dois sons se confundem.
- **/ʃ/ em *ship, should***: o som é o de "ch" em "chave", com os lábios um pouco avançados; evite /s/ puro.
- **Consoantes finais**: em *first, asked, texts*, feche a sílaba final sem acrescentar vogal ("firsti", "textsi").
- **Ritmo**: em frases de instrução, o verbo vem primeiro e recebe a ênfase natural — *SKIM the title*, *SCAN the note*.

### Prompt de produção (oral ou escrita)

Imagine a daily reunião da sua equipe. Escreva ou fale **4 a 6 linhas** em que você: (1) explica que a nota é longa, (2) diz que vai *skimming* para a ideia geral, (3) diz que vai *scanning* para um detalhe (data, número, nome de serviço), e (4) escolhe um trecho para *read carefully*. Use pelo menos duas palavras do glossário da FASE 1 e, se possível, um detalhe real do seu trabalho (incidente, release note, fila de tickets).
