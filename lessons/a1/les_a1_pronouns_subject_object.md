## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **subject pronoun** | pronome sujeito | *I, you, he, she, it, we, they* |
| **object pronoun** | pronome objeto | *me, you, him, her, it, us, them* |
| **I** | eu | *sujeito 1ª pessoa* |
| **me** | mim | *objeto 1ª pessoa* |
| **you** | você | *sujeito/objeto 2ª pessoa* |
| **he** | ele | *sujeito 3ª pessoa masculino* |
| **him** | ele (objeto) | *objeto 3ª pessoa masculino* |
| **she** | ela | *sujeito 3ª pessoa feminino* |
| **her** | ela (objeto) | *objeto 3ª pessoa feminino* |
| **it** | ele/ela (coisa) | *sujeito/objeto 3ª pessoa neutro* |
| **we** | nós | *sujeito 1ª pessoa plural* |
| **us** | nós (objeto) | *objeto 1ª pessoa plural* |
| **they** | eles/elas | *sujeito 3ª pessoa plural* |
| **them** | eles/elas (objeto) | *objeto 3ª pessoa plural* |

### Mini-texto (áudio: `deferred_render`)

> "**Subject pronouns**: **I** am happy. **You** are here. **He** is tall. **She** is smart. **It** is a book. **We** are friends. **They** are students."
>
> "**Object pronouns**: Help **me**. See **you**. Call **him**. Visit **her**. Read **it**. Join **us**. Tell **them**."
>
> "**I** love **you**. **She** likes **him**. **They** help **us**."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Subject pronouns** are:
| Slot | Value |
|------|-------|
| A | me, you, him, her, us, them |
| B | **I, you, he, she, it, we, they** |
| C | my, your, his, her, our, their |
| D | mine, yours, his, hers, ours, theirs |
**Key:** B
**br_pt_form:** "pronomes sujeito / I, you, he, she, it, we, they"

### Item 2 — Vocabulary (Matching)
Match the subject to its object:
| Subject | Object |
|---------|--------|
| **I** | a. me |
| **He** | b. him |
| **She** | c. her |
| **They** | d. them |
**Key:** I→a, He→b, She→c, They→d
**br_pt_form:** "eu/mim", "ele/ele", "ela/ela", "eles/eles"

### Item 3 — Grammar: Subject vs object position (fill-in-blank)
Complete with **subject or object pronoun**:
"______ (I/me) am happy. Help ______ (I/me). ______ (He/him) is tall. Call ______ (he/him)."
**Key:** I / me / He / him
**br_pt_form:** "Eu / mim / Ele / ele"

## FASE 3 — Output Task [4 min]

### Speaking: Pronoun Chain (grupo)
**Game**: Each person says a sentence with subject + verb + object pronoun.

**Example:**
> A: "I see you."
> B: "You call him."
> C: "He helps her."
> D: "She tells us."
> E: "We join them."
> F: "They help me."

**Create your own chain** with 6 sentences.

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Object pronouns** are used:
| Slot | Value |
|------|-------|
| A | Before the verb |
| B | **After the verb or preposition** |
| C | As subjects |
| D | Only in questions |
**Key:** B
**br_pt_form:** "pronomes objeto / após verbo ou preposição"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **pronoun**:
| Slot | Value |
|------|-------|
| A | **Me** am happy. |
| B | **I** am happy. |
| C | **Him** is tall. |
| D | **Her** is smart. |
**Key:** B
**br_pt_form:** "Eu estou feliz."
