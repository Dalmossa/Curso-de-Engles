## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **present simple** | presente simples | *hábitos, fatos, rotinas* |
| **affirmative** | afirmativa | *frase positiva* |
| **I work** | eu trabalho | *1ª pessoa* |
| **you work** | você trabalha | *2ª pessoa* |
| **he/she/it works** | ele/ela trabalha | *3ª pessoa + -s* |
| **we work** | nós trabalhamos | *1ª pessoa plural* |
| **they work** | eles trabalham | *3ª pessoa plural* |
| **habit** | hábito | *ação repetida* |
| **routine** | rotina | *atividade regular* |
| **fact** | fato | *verdade geral* |
| **always** | sempre | *frequência 100%* |
| **usually** | geralmente | *frequência alta* |
| **sometimes** | às vezes | *frequência média* |
| **never** | nunca | *frequência 0%* |

### Mini-texto (áudio: `deferred_render`)

> "**Present simple** for habits and facts: **I work** every day. **She works** in a hospital. **They work** on weekends."
>
> "**He/She/It** adds **-s**: work**s**, play**s**, watch**es**, stud**ies**."
>
> "**Frequency adverbs**: **always, usually, sometimes, never**. **I always drink coffee. She never eats meat**."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**He/She/It** in present simple:
| Slot | Value |
|------|-------|
| A | Uses base verb |
| B | **Adds -s to verb** |
| C | Uses -ing |
| D | Uses -ed |
**Key:** B
**br_pt_form:** "ele/ela / adiciona -s ao verbo"

### Item 2 — Vocabulary (Matching)
Match the subject to its verb form:
| Subject | Verb |
|---------|------|
| **I** | a. work |
| **He** | b. works |
| **They** | c. work |
| **She** | d. works |
**Key:** I→a, He→b, They→c, She→d
**br_pt_form:** "eu / ele / eles / ela"

### Item 3 — Grammar: Present simple -s (fill-in-blank)
Complete with **base verb or -s form**:
"I ______ (work). She ______ (work). They ______ (work). He ______ (play)."
**Key:** work / works / work / plays
**br_pt_form:** "trabalho / trabalha / trabalham / joga"

---

## FASE 3 — Output Task [4 min]

### Speaking: Daily Routine (individual)
**Describe your daily routine** using present simple + frequency adverbs.

**Example:**
> "I **always** wake up at 7. I **usually** drink coffee. I **sometimes** eat bread. I **never** skip breakfast. I **always** work from 9 to 6."

**Create your own routine** with 5 sentences.
