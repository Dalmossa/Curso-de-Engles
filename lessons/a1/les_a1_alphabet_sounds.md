## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Vowels** in English are:
| Slot | Value |
|------|-------|
| A | B, C, D, F, G |
| B | **A, E, I, O, U** |
| C | A, B, C, D, E |
| D | X, Y, Z |
**Key:** B
**br_pt_form:** "vogais / A, E, I, O, U"

### Item 2 — Vocabulary (Matching)
Match the letter type to its example:
| Type | Example |
|------|---------|
| **Vowel** | a. A |
| **Consonant** | b. B |
| **Uppercase** | c. C |
| **Lowercase** | d. d |
**Key:** Vowel→a, Consonant→b, Uppercase→c, Lowercase→d
**br_pt_form:** "vogal", "consoante", "maiúscula", "minúscula"

### Item 3 — Grammar: Articles with letters (fill-in-blank)
Complete with **a / an**:
"______ A, ______ B, ______ F, ______ H, ______ M, ______ S, ______ X."
**Key:** an / a / an / an / an / an / an
**br_pt_form:** "um / uma"

## FASE 3 — Output Task [4 min]

### Speaking: Alphabet Practice (individual)
**Tasks:**
1. Sing the **ABC song** (or recite alphabet)
2. Spell your name: "My name is ______" — letter by letter
3. Spell 5 words: cat, dog, book, pen, sun
4. Identify vowels in: "English is fun"

**Use:** *alphabet, letter, vowel, consonant, sound, letter name, pronunciation, phonetics, spelling, uppercase, lowercase, ABC song*.
