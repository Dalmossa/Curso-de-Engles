## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **negotiation** | negociação | *processo de acordo mútuo* |
| **compromise** | compromisso / acordo | *cada lado cede um pouco* |
| **win-win** | ganha-ganha | *resultado benéfico para ambos* |
| **bottom line** | limite / linha final | *ponto além do qual não cede* |
| **concession** | concessão | *ceder em um ponto* |
| **counteroffer** | contraproposta | *resposta a uma proposta* |
| **leverage** | alavanca / vantagem | *fator que fortalece posição* |
| **deadlock** | impasse | *nenhum lado cede* |
| **walk away** | sair / desistir | *encerrar negociação sem acordo* |
| **BATNA** | BATNA | *Best Alternative To Negotiated Agreement* |
| **anchoring** | ancoragem | *primeira oferta que define referência* |
| **rapport** | rapport / empatia | *conexão e confiança mútua* |

### Mini-texto (áudio: `deferred_render`)

> **Vendor:** "Price: $100k/year. **Anchor** high."
>
> **Client:** "Budget: $70k. **Counteroffer**: $75k with 2-year contract."
>
> **Vendor:** "**Concession**: $85k, but 3 years. **Leverage**: we include premium support."
>
> **Client:** "**Compromise**: $80k, 3 years, premium support. **Win-win**."
>
> **Both:** "Deal. **Rapport** built. **BATNA** was weak for both — no better alternative."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**BATNA** stands for:
| Slot | Value |
|------|-------|
| A | Best Alternative To Negotiated Agreement |
| B | **Best Alternative To Negotiated Agreement** |
| C | Basic Agreement To Negotiate Always |
| D | Best Approach To New Agreement |
**Key:** B
**br_pt_form:** "Melhor Alternativa a um Acordo Negociado"

### Item 2 — Vocabulary (Matching)
Match the negotiation term to its meaning:
| Term | Meaning |
|------|---------|
| **Counteroffer** | a. Response to an offer with different terms |
| **Concession** | b. Giving up something to reach agreement |
| **Deadlock** | c. Neither side moves |
| **Walk away** | d. End negotiation without deal |
**Key:** Counteroffer→a, Concession→b, Deadlock→c, Walk away→d
**br_pt_form:** "contraproposta", "concessão", "impasse", "sair"

### Item 3 — Grammar: Second conditional for hypothetical negotiations (fill-in-blank)
Complete with **second conditional** (if + past, would + verb):
"If they ______ (offer) $90k, we ______ (accept). If we ______ (have) better BATNA, we ______ (push) harder."
**Key:** offered / would accept / had / would push
**br_pt_form:** "oferecessem / aceitaríamos / tivéssemos / pressionaríamos"

## FASE 3 — Output Task [4 min]

### Speaking: Negotiation Role-play (pares)
**Student A (Vendor):** Negotiate software license. Use: *negotiation, compromise, win-win, bottom line, concession, counteroffer, leverage, deadlock, walk away, BATNA, anchoring, rapport*.
**Student Buyer:** Push for lower price, more features.
**Goal:** Reach **win-win** or identify **deadlock**.

**Script:**
> **Vendor:** "**Anchor**: $100k/year, includes premium support."
> **Buyer:** "$70k is **bottom line**. **Counteroffer**: $75k."
> **Vendor:** "**Concession**: $85k, 3-year lock. **Leverage**: 24/7 support."
> **Buyer:** "$80k, 3 years. **Win-win**."

|------|-------|
| A | Take a break |
| B | **End negotiation without agreement** |
| C | Change topic |
| D | Ask for time |
**Key:** B
**br_pt_form:** "sair / desistir da negociação"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **second conditional**:
| Slot | Value |
|------|-------|
| A | If we **had** better leverage, we **would get** better terms. |
| B | If we **have** better leverage, we **would get** better terms. |

| D | If we **have** better leverage, we **will get** better terms. |
**Key:** A
