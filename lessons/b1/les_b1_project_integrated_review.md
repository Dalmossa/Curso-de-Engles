## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Paraphrase** means:
| Slot | Value |
|------|-------|
| A | Copy exactly |
| B | **Rewrite in own words, same meaning** |
| C | Translate |
| D | Summarize in one word |
**Key:** B
**br_pt_form:** "parafrasear / reescrever com outras palavras"

### Item 2 — Vocabulary (Matching)
Match the skill to its focus:
| Skill | Focus |
|-------|-------|
| **Summarize** | a. Main points only |
| **Paraphrase** | b. Same meaning, new words |
| **Synthesize** | c. Combine multiple sources |
| **Critical thinking** | d. Analyze, evaluate, question |
**Key:** Summarize→a, Paraphrase→b, Synthesize→c, Critical thinking→d
**br_pt_form:** "resumir", "parafrasear", "sintetizar", "pensamento crítico"

### Item 3 — Grammar: Connectors for coherence (fill-in-blank)
Complete with **cohesive devices**:
"The argument is strong; **______**, it lacks evidence. **______**, the conclusion follows. **______**, we recommend more data."
**Key:** however / therefore / in conclusion
**br_pt_form:** "no entanto", "portanto", "em conclusão"

---

## FASE 3 — Output Task [4 min]

### Writing + Speaking: Integrated Review Cycle (individual → pares)
**Cycle (15 min):**
1. **Read** short tech article (2 min)
2. **Summarize** in 3 sentences (3 min)
3. **Paraphrase** one key sentence (2 min)
4. **Speak** to partner: explain main idea + your opinion (4 min)
5. **Peer feedback** + **Self-assessment** (2 min)
6. **Action plan**: 1 concrete step (2 min)

**Article prompt:** "Technical debt slows velocity. Refactoring pays off long-term. Teams must allocate 20% sprint capacity."

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Coherence** vs **cohesion**:
| Slot | Value |
|------|-------|
| A | Same thing |
| B | **Coherence = logical flow; cohesion = grammatical links** |
| C | Coherence = grammar; cohesion = logic |
| D | Both mean grammar |
**Key:** B
**br_pt_form:** "coerência = fluxo lógico; coesão = links gramaticais"

### Item 2 — Grammar (L1, adaptive)
Choose the correct connector for **contrast**:
| Slot | Value |
|------|-------|
| A | The code works; **therefore**, it has bugs. |
| B | The code works; **however**, it has bugs. |
| C | The code works; **furthermore**, it has bugs. |
| D | The code works; **thus**, it has bugs. |
**Key:** B
**br_pt_form:** "O código funciona; no entanto, tem bugs."
