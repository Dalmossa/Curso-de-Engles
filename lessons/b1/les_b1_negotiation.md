## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **negotiation** | negociação | *processo de acordo* |
| **compromise** | compromisso / acordo | *cada lado cede* |
| **counteroffer** | contraproposta | *resposta a uma proposta* |
| **concession** | concessão | *ceder em um ponto* |
| **deadline** | prazo | *data limite* |
| **agreement** | acordo | *resultado da negociação* |
| **proposal** | proposta | *oferta inicial* |
| **terms** | termos / condições | *detalhes do acordo* |
| **win-win** | ganha-ganha | *resultado benéfico para ambos* |
| **walk away** | sair / desistir | *encerrar sem acordo* |
| **leverage** | alavanca / vantagem | *fator que fortalece posição* |
| **bottom line** | limite / linha final | *ponto além do qual não cede* |

### Mini-texto (áudio: `deferred_render`)

> A: Our **proposal** is $100k. That's our **bottom line**.
> B: We can offer $80k. That's our best **counteroffer**.
> A: Let's **compromise** at $90k. **Win-win**.
> B: Agreed. What are the **terms**?
> A: 30-day payment, 1-year warranty.
> B: Deal. Let's sign the **agreement**.

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Win-win** in negotiation means:
| Slot | Value |
|------|-------|
| A | One side wins big |
| B | **Both sides benefit** |
| C | No agreement |
| D | Both sides lose |
**Key:** B
**br_pt_form:** "win-win / ambos os lados se beneficiam"

### Item 2 — Vocabulary (Matching)
Match the negotiation term to its meaning:
| Term | Meaning |
|------|---------|
| **Compromise** | a. Each side gives up something |
| **Counteroffer** | b. Response to an offer |
| **Concession** | c. Giving up a point |
| **Walk away** | d. End without deal |
**Key:** Compromise→a, Counteroffer→b, Concession→c, Walk away→d
**br_pt_form:** "compromisso", "contraproposta", "concessão", "sair"

### Item 3 — Grammar: Conditionals for negotiation (fill-in-blank)
Complete with **conditional**:
"If you ______ (offer) $90k, we ______ (accept). If we ______ (not agree), we ______ (walk away)."
**Key:** offer / will accept / don't agree / will walk away
**br_pt_form:** "oferecer / aceitaremos / não concordarmos / sairemos"

### Item 1 — Vocabulary (L1, adaptive)
**Leverage** in negotiation means:
| Slot | Value |
|------|-------|
| A | A deadline |
| B | **A factor that strengthens your position** |
| C | A compromise |
| D | A concession |
**Key:** B
**br_pt_form:** "leverage / fator que fortalece sua posição"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **conditional**:
| Slot | Value |
|------|-------|
| A | If you **offer** $90k, we **will accept**. |
| B | If you **offered** $90k, we **will accept**. |
| C | If you **offer** $90k, we **would accept**. |
| D | If you **offered** $90k, we **would accepted**. |
**Key:** A
**br_pt_form:** "Se você oferecer $90k, aceitaremos."
