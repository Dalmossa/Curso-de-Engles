## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **conditional** | condicional | *if + result* |
| **first conditional** | primeiro condicional | *possível, real* |
| **second conditional** | segundo condicional | *improvável, hipotético* |
| **if clause** | oração com if | *condição* |
| **result clause** | oração resultado | *consequência* |
| **if + present** | if + presente | *first conditional* |
| **if + past** | if + passado | *second conditional* |
| **will** | vai | *resultado first conditional* |
| **would** | iria / gostaria | *resultado second conditional* |
| **unless** | a menos que | *condição negativa* |
| **as long as** | desde que | *condição* |
| **in case** | no caso de | *precaução* |

### Mini-texto (áudio: `deferred_render`)

> "**First conditional** (possible): 'If it **rains**, I **will stay** home.' 'If you **study**, you **will pass**.'"
>
> "**Second conditional** (unlikely/hypothetical): 'If I **had** money, I **would buy** a car.' 'If she **were** here, she **would help**.'"
>
> "**Unless/As long as/In case**: '**Unless** you hurry, you'll be late.' '**As long as** you try, you'll improve.' 'Take an umbrella **in case** it rains.'"

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**First conditional** is used for:
| Slot | Value |
|------|-------|
| A | Hypothetical situations |
| B | **Possible, real situations** |
| C | Past situations |
| D | General facts |
**Key:** B
**br_pt_form:** "primeiro condicional / situações possíveis, reais"

### Item 2 — Vocabulary (Matching)
Match the conditional to its structure:
| Conditional | Structure |
|-------------|-----------|
| **First** | a. If + present, will + verb |
| **Second** | b. If + past, would + verb |
| **Unless** | c. Negative condition |
| **In case** | d. Precaution |
**Key:** First→a, Second→b, Unless→c, In case→d
**br_pt_form:** "primeiro", "segundo", "a menos que", "no caso de"

### Item 3 — Grammar: Conditionals (fill-in-blank)
Complete with **correct conditional**:
"If it ______ (rain), I ______ (stay) home. If I ______ (have) money, I ______ (buy) a car."
**Key:** rains / will stay / had / would buy
**br_pt_form:** "chover / ficaria / tivesse / compraria"

## FASE 3 — Output Task [4 min]

### Speaking: Conditional Scenarios (pares)
**Create conditional sentences** for work scenarios.

**Scenarios:**
1. If you finish early, you can leave. (first)
2. If I were the manager, I would change the process. (second)
3. Unless you hurry, you'll miss the meeting. (unless)
4. Take your laptop in case you need to work. (in case)

**Create 6 conditional sentences** using first, second, unless, in case.

### Item 1 — Vocabulary (L1, adaptive)

|------|-------|
| A | If |
| B | **If not / except if** |
| C | As long as |
| D | In case |
**Key:** B
**br_pt_form:** "unless / se não / exceto se"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **conditional structure**:
| Slot | Value |
|------|-------|
| A | If I **have** money, I **would buy** a car. |
| B | If I **had** money, I **would buy** a car. |
| C | If I **have** money, I **will buy** a car. (hypothetical) |
| D | If I **had** money, I **will buy** a car. |
**Key:** B
**br_pt_form:** "Se eu tivesse dinheiro, compraria um carro."
