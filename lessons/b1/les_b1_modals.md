## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **modal verb** | verbo modal | *can, could, may, might, must, should, would* |
| **can** | poder / conseguir | *habilidade, permissão* |
| **could** | poderia | *habilidade passada, pedido educado* |
| **may** | poder | *permissão formal, possibilidade* |
| **might** | talvez | *possibilidade* |
| **must** | deve / tem que | *obrigação* |
| **should** | deveria | *conselho* |
| **would** | gostaria / iria | *condicional, pedido educado* |
| **ability** | habilidade | *capacidade* |
| **permission** | permissão | *autorização* |
| **possibility** | possibilidade | *algo possível* |
| **obligation** | obrigação | *dever* |
| **advice** | conselho | *recomendação* |

### Mini-texto (áudio: `deferred_render`)

> "**Can**: 'I **can** swim.' (ability) '**Can** I leave?' (permission)"
>
> "**Could**: 'I **could** swim when I was young.' (past ability) '**Could** you help me?' (polite request)"
>
> "**May/Might**: 'It **may** rain.' (possibility) 'I **might** go.' (uncertain)"
>
> "**Must/Should**: 'You **must** wear a helmet.' (obligation) 'You **should** rest.' (advice)"

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Could** is used for:
| Slot | Value |
|------|-------|
| A | Present ability |
| B | **Past ability and polite requests** |
| C | Future possibility |
| D | Obligation |
**Key:** B
**br_pt_form:** "could / habilidade passada e pedidos educados"

### Item 2 — Vocabulary (Matching)
Match the modal to its function:
| Modal | Function |
|-------|----------|
| **Can** | a. Ability / permission |
| **Could** | b. Past ability / polite request |
| **May** | c. Formal permission / possibility |
| **Must** | d. Obligation |
**Key:** Can→a, Could→b, May→c, Must→d
**br_pt_form:** "can", "could", "may", "must"

### Item 3 — Grammar: Modal + base verb (fill-in-blank)
Complete with **modal + base verb**:
"I ______ (can/swim). She ______ (could/help). They ______ (may/come). He ______ (must/leave)."
**Key:** can swim / could help / may come / must leave
**br_pt_form:** "posso nadar / poderia ajudar / podem vir / deve sair"

## FASE 3 — Output Task [4 min]

### Speaking: Modal Scenarios (pares)
**Create sentences** using modals in work scenarios.

**Scenarios:**
1. Ask for permission (can/could/may)
2. Give advice (should)
3. Express obligation (must)
4. Express possibility (may/might)

**Example:**
> A: "**Could** I leave early today?"
> B: "Yes, you **can**. You **should** finish the report first."
> A: "I **must** attend a meeting at 3."
> B: "You **might** want to reschedule."
