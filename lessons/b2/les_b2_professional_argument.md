| **claim** | afirmação / alegação | *ponto que se defende* |

### Mini-texto (áudio: `deferred_render`)

> **Professor:** "**Argumentative essay**: **thesis** → **claims** → **evidence** → **counterargument** → **rebuttal** → **conclusion**."
>
> "Example: *Remote work improves productivity* (**thesis**). **Claim**: fewer distractions. **evidence**: study X shows +20%. **Counterargument**: collaboration suffers. **Rebuttal**: async tools compensate. **Conclusion**: adopt hybrid model."
>
> "**Coherence**: **transitions** (*however, furthermore, consequently*). **Hedging**: *suggests*, *may indicate*. **Citation**: (Author, Year)."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
A **thesis statement** is:
| Slot | Value |
|------|-------|
| A | A question |
| B | **One sentence stating the central position** |
| C | A summary |
| D | A quote |
**Key:** B
**br_pt_form:** "tese / uma frase com a posição central"

### Item 2 — Vocabulary (Matching)
Match the essay component to its function:
| Component | Function |
|-----------|----------|
| **Claim** | a. Position you defend |
| **Counterargument** | b. Opposing view acknowledged |
| **Rebuttal** | c. Response to counterargument |
| **Evidence** | d. Data supporting claim |
**Key:** Claim→a, Counterargument→b, Rebuttal→c, Evidence→d
**br_pt_form:** "afirmação", "contra-argumento", "refutação", "evidência"

### Item 3 — Grammar: Transitions for argumentation (fill-in-blank)
Complete with **transitions**:
"Remote work increases focus. **______,** it reduces commute stress. **______,** collaboration may suffer. **______,** async tools help."
**Key:** Furthermore / However / Consequently
**br_pt_form:** "Além disso / No entanto / Consequentemente"

## FASE 3 — Output Task [4 min]

### Writing: Mini Argumentative Essay (individual)
**Write 150 words:** "Technical debt should be prioritized over new features."

**Structure:**
1. **Thesis** (1 sentence)
2. **Claim 1 + Evidence** (2-3 sentences)
3. **Counterargument + Rebuttal** (2-3 sentences)
4. **Conclusion** (1-2 sentences)

**Use:** *thesis, claim, counterargument, rebuttal, evidence, reasoning, conclusion, coherence, transition, hedging, citation*.

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Rebuttal** in argumentation:
| Slot | Value |
|------|-------|
| A | Agreeing with opponent |
| B | **Responding to counterargument with reasoning** |
| C | Ignoring opposition |
| D | Changing topic |
**Key:** B
**br_pt_form:** "refutação / responder ao contra-argumento"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **transition** for contrast:
| Slot | Value |
|------|-------|
| A | Productivity rose. **Furthermore**, errors increased. |
| B | Productivity rose. **However**, errors increased. |
| C | Productivity rose. **Consequently**, errors increased. |
| D | Productivity rose. **Similarly**, errors increased. |
**Key:** B
**br_pt_form:** "A produtividade aumentou. No entanto, os erros aumentaram."
