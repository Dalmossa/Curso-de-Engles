## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **review** | revisão / avaliação | *análise crítica de trabalho* |
| **evaluation** | avaliação | *juízo de valor com critérios* |
| **criteria** | critérios | *padrões de julgamento* |
| **rubric** | rubrica | *matriz de avaliação com níveis* |
| **constructive feedback** | feedback construtivo | *específico, acionável, equilibrado* |
| **strengths** | pontos fortes | *o que funciona bem* |
| **areas for improvement** | áreas de melhoria | *o que pode evoluir* |
| **evidence-based** | baseado em evidência | *fundamentado em exemplos* |
| **bias** | viés | *preconceito que distorce avaliação* |
| **calibration** | calibração | *alinhar avaliadores ao mesmo padrão* |
| **peer review** | revisão por pares | *avaliação entre colegas* |
| **self-evaluation** | autoavaliação | *avaliar próprio trabalho* |

### Mini-texto (áudio: `deferred_render`)

> **Manager:** "**Review** = evaluate against **criteria**. Use **rubric**: *Exceeds / Meets / Approaching / Below*."
>
> **Employee:** "**Constructive feedback**: *Strength* — code is clean. *Area for improvement* — add integration tests. **Evidence-based**: *Line 45 lacks test coverage*."
>
> **Manager:** "Watch **bias**: recency, halo, similarity. **Calibration** session aligns reviewers. **Peer review** + **self-evaluation** = 360° view."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Constructive feedback** is:
| Slot | Value |
|------|-------|
| A | Only praise |
| B | **Specific, actionable, balanced (strengths + improvements)** |
| C | Only criticism |
| D | Vague suggestions |
**Key:** B
**br_pt_form:** "feedback construtivo / específico, acionável, equilibrado"

### Item 2 — Vocabulary (Matching)
Match the review component to its purpose:
| Component | Purpose |
|-----------|---------|
| **Criteria** | a. Standards for judgment |
| **Rubric** | b. Matrix with performance levels |
| **Evidence-based** | c. Supported by concrete examples |
| **Bias** | d. Systematic distortion to avoid |
**Key:** Criteria→a, Rubric→b, Evidence-based→c, Bias→d
**br_pt_form:** "critérios", "rubrica", "baseado em evidência", "viés"

### Item 3 — Grammar: Reported speech for feedback (fill-in-blank)
Convert to **reported speech**:
"Your code is clean. → He said my code ______ clean."
"You need more tests. → She said I ______ more tests."
**Key:** was / needed
**br_pt_form:** "estava / precisava"

---

## FASE 3 — Output Task [4 min]

### Writing: Performance Review (individual)
**Scenario:** Write a **peer review** for a colleague's project delivery. Use **rubric** with 4 criteria. Include:

- **Strengths** (2 specific, evidence-based)
- **Areas for improvement** (2 specific, actionable)
- **Overall rating** (Exceeds / Meets / Approaching / Below)
- **One development suggestion**

**Criteria:** Code Quality | Delivery | Collaboration | Documentation

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Calibration** in review means:
| Slot | Value |
|------|-------|
| A | Adjusting monitor |
| B | **Aligning reviewers to same standard** |
| C | Setting deadlines |
| D | Writing rubric |
**Key:** B
**br_pt_form:** "calibração / alinhar avaliadores"

### Item 2 — Grammar (L1, adaptive)
Choose correct **reported speech**:
| Slot | Value |
|------|-------|
| A | He said the work *is* excellent. |
| B | He said the work *was* excellent. |
| C | He said the work *will be* excellent. |
| D | He said the work *be* excellent. |
**Key:** B
**br_pt_form:** "Ele disse que o trabalho era excelente."
