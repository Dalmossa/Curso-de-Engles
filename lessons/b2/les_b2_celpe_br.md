## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Self-correction** in speaking:
| Slot | Value |
|------|-------|
| A | Is penalized |
| B | **Shows language awareness and is acceptable** |
| C | Is ignored |
| D | Is forbidden |
**Key:** B
**br_pt_form:** "autocorreção / mostra consciência linguística"

### Item 2 — Vocabulary (Matching)
Match the speaking skill to its description:
| Skill | Description |
|-------|-------------|
| **Fluency** | a. Speak without excessive pauses |
| **Accuracy** | b. Correct grammar and vocabulary |
| **Coherence** | c. Logically connected ideas |
| **Interaction** | d. Natural dialogue with examiner |
**Key:** Fluency→a, Accuracy→b, Coherence→c, Interaction→d
**br_pt_form:** "fluência", "precisão", "coerência", "interação"

### Item 3 — Grammar: Present continuous for speaking performance (fill-in-blank)
Complete with **present continuous**:
"The candidate ______ (speak) fluently. She ______ (answer) the questions. They ______ (interact) well."
**Key:** is speaking / is answering / are interacting
**br_pt_form:** "está falando", "está respondendo", "estão interagindo"

## FASE 3 — Output Task [4 min]

### Speaking: CELPE-Bras Simulation (pares)
**Student A (Examiner):** Ask questions + give task.
**Student B (Candidate):** Respond with fluency, accuracy, coherence.

**Part 1 (5 min):** Personal questions (hometown, work, interests).
**Part 2 (10 min):** Task — read short article → express opinion → justify → conclude.

**Example task:** "Article: Remote work is becoming standard. Do you agree? Justify."
