### Mini-texto (áudio: `deferred_render`)

> **Professor:** "**Summarizing**: read → identify **main idea** → extract **key points** → **paraphrase** → **omit** details → **condense**."
>
> "Original: 500 words. **Summary**: 50 words. **Objective**: no opinion. **Concise**: every word counts."
>
> "**Abstract**: 150 words, structured (background, method, results, conclusion). **TL;DR**: 1 sentence for busy readers."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
A **summary** should:
| Slot | Value |
|------|-------|
| A | Include all details |
| B | **Condense main ideas, omit details, stay objective** |
| C | Add opinions |
| D | Be longer than original |
**Key:** B
**br_pt_form:** "resumo / condensar ideias principais, omitir detalhes, objetivo"

### Item 2 — Vocabulary (Matching)
Match the summary type to its use:
| Type | Use |
|------|-----|
| **Abstract** | a. Academic paper opening |
| **TL;DR** | b. Quick takeaway for busy readers |
| **Executive summary** | c. Business decision-makers |
| **Paraphrase** | d. Same meaning, new words |
**Key:** Abstract→a, TL;DR→b, Executive summary→c, Paraphrase→d
**br_pt_form:** "abstract", "TL;DR", "resumo executivo", "paráfrase"

### Item 3 — Grammar: Nominalization for conciseness (fill-in-blank)
Rewrite with **nominalization**:
"The team *analyzed* the data. → The team conducted an ______ of the data."
"The system *performs* well. → The system's ______ is excellent."
**Key:** analysis / performance
**br_pt_form:** "análise", "desempenho"

## FASE 3 — Output Task [4 min]

### Writing: Summary Transformation (individual)
**Read this paragraph (80 words) and write a 25-word summary:**

> "Microservices architecture decomposes applications into small, independent services. Each service owns its data and communicates via APIs. Benefits include independent deployment, technology diversity, and fault isolation. Challenges include distributed complexity, network latency, and operational overhead. Teams must invest in observability, CI/CD, and service mesh to succeed."

**Target:** 25 words, objective, concise, main idea + key points only.

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Objective** summary means:
| Slot | Value |
|------|-------|
| A | With opinions |
| B | **Without personal opinion** |
| C | With recommendations |
| D | With predictions |
**Key:** B
**br_pt_form:** "objetivo / sem opinião pessoal"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **nominalization**:
| Slot | Value |
|------|-------|
| A | The team *decided* quickly. → The team's *decide* was quick. |
| B | The team *decided* quickly. → The team's *decision* was quick. |
| C | The team *decided* quickly. → The team's *deciding* was quick. |
| D | The team *decided* quickly. → The team's *decided* was quick. |
**Key:** B
**br_pt_form:** "A decisão da equipe foi rápida."
