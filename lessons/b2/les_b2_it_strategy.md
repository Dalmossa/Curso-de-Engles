### Mini-texto (áudio: `deferred_render`)

> **CTO:** "**Technical strategy**: **vision** = platform-first, API-driven. **Mission** = enable product teams to ship fast."
>
> "**Roadmap**: Q1 migrate to K8s. Q2 service mesh. Q3 multi-region. **OKRs**: 99.99% availability, p99 < 100ms, deploy 10x/day."
>
> "**Alignment**: engineering, product, ops — same **KPIs**. **Stakeholder buy-in**: monthly **executive summary**. **Risk assessment**: single region dependency — mitigate with multi-region."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**OKR** stands for:
| Slot | Value |
|------|-------|
| A | Objectives and Key Results |
| B | **Objectives and Key Results** |
| C | Operational Knowledge Review |
| D | Objective Key Resources |
**Key:** B
**br_pt_form:** "Objetivos e Resultados-Chave"

### Item 2 — Vocabulary (Matching)
Match the strategy term to its purpose:
| Term | Purpose |
|------|---------|
| **Vision** | a. Desired future state |
| **Roadmap** | b. Temporal plan of deliverables |
| **KPI** | c. Measurable performance indicator |
| **Alignment** | d. Sync between teams/goals |
**Key:** Vision→a, Roadmap→b, KPI→c, Alignment→d
**br_pt_form:** "visão", "roadmap", "KPI", "alinhamento"

### Item 3 — Grammar: Future forms for strategy (fill-in-blank)
Complete with **will / going to / present continuous**:
"We ______ (migrate) to K8s next quarter. The team ______ (present) the roadmap Monday. I ______ (align) with product on OKRs."
**Key:** will migrate / is presenting / am going to align
**br_pt_form:** "vamos migrar", "vai apresentar", "vou alinhar"

---

## FASE 3 — Output Task [4 min]

### Writing: Strategy One-Pager (individual)
**Write a 1-page technical strategy** for: "Migrate monolith to microservices over 12 months."

**Include:**
- **Vision** (1 sentence)
- **Mission** (1 sentence)
- **Roadmap** (3 quarters with milestones)
- **OKRs** (2 objectives, 3 key results each)
- **Risks** (2 risks + mitigations)
- **Stakeholders** (who needs **buy-in**)

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Stakeholder buy-in** means:
| Slot | Value |
|------|-------|
| A | Stakeholders pay for project |
| B | **Stakeholders support and commit to the strategy** |
| C | Stakeholders attend meetings |
| D | Stakeholders write code |
**Key:** B
**br_pt_form:** "adesão das partes interessadas / apoio e comprometimento"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **future form** for a planned roadmap:
| Slot | Value |
|------|-------|
| A | We **migrate** to K8s next quarter. |
| B | We **are migrate** to K8s next quarter. |
| C | We **will migrate** to K8s next quarter. |
| D | We **migrating** to K8s next quarter. |
**Key:** C
**br_pt_form:** "Vamos migrar para K8s no próximo trimestre."
