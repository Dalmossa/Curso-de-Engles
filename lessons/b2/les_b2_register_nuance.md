## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **register** | registro / nível de formalidade | *adequação da língua ao contexto* |
| **nuance** | nuance / matiz | *diferença sutil de significado* |
| **formal** | formal | *contexto oficial, acadêmico, legal* |
| **informal** | informal | *contexto casual, entre pares* |
| **hedging** | hedge / atenuação | *suavizar afirmação (ex: *seems*, *may*)* |
| **downtoner** | atenuador | *reduz intensidade (ex: *slightly*, *somewhat*)* |
| **intensifier** | intensificador | *aumenta intensidade (ex: *extremely*, *absolutely*)* |
| **euphemism** | eufemismo | *termo suave para algo desagradável* |
| **implicature** | implicatura | *significado implícito, não dito* |
| **politeness strategy** | estratégia de polidez | *face-saving, indirectness* |
| **register shift** | mudança de registro | *adaptar formalidade ao público* |
| **pragmatic competence** | competência pragmática | *saber o que dizer, como, quando* |

### Mini-texto (áudio: `deferred_render`)

> **Coach:** "**Register** = match language to context. Email to CEO ≠ Slack to teammate."
>
> **Student:** "**Formal**: *We regret to inform you...* **Informal**: *Sorry, can't make it.* **Hedging**: *It seems likely...* vs *It is certain.* **Downtoner**: *slightly delayed*. **Intensifier**: *absolutely critical*."
>
> **Coach:** "**Euphemism**: *let go* (not *fire*). **Implicature**: *Can you open the window?* = *Please open it.* **Register shift**: adapt to audience — **pragmatic competence**."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Hedging** in professional English:
| Slot | Value |
|------|-------|
| A | Making absolute statements |
| B | **Softening certainty (may, seems, likely)** |
| C | Using slang |
| D | Being rude |
**Key:** B
**br_pt_form:** "hedge / atenuação / suavizar certeza"

### Item 2 — Vocabulary (Matching)
Match the device to its function:
| Device | Function |
|--------|----------|
| **Downtoner** | a. Reduce intensity (*slightly*) |
| **Intensifier** | b. Increase intensity (*absolutely*) |
| **Euphemism** | c. Soften unpleasant term (*pass away*) |
| **Implicature** | d. Implied meaning (*It's cold* → close window) |
**Key:** Downtoner→a, Intensifier→b, Euphemism→c, Implicature→d
**br_pt_form:** "atenuador", "intensificador", "eufemismo", "implicatura"

### Item 3 — Grammar: Hedging with modals/adverbs (fill-in-blank)
Rewrite with **hedging**:
"The project *will* fail. → The project ______ fail."
"The solution *is* perfect. → The solution ______ be perfect."
**Key:** may / might / could / appears to
**br_pt_form:** "pode falhar", "parece ser"

## FASE 3 — Output Task [4 min]

### Writing: Register Transformation (individual)
**Task:** Rewrite 3 sentences for **different registers**:

1. **Formal email to client**: "We can't deliver on time."
2. **Casual Slack to teammate**: "The deployment failed."
3. **Executive summary**: "This approach is risky."

**Target:** Use *hedging, downtoners, intensifiers, euphemisms, politeness strategies* appropriately.

## FASE 4 — Shadow CAT [2 min]

### Item 1 — Vocabulary (L1, adaptive)
**Implicature** example:
| Slot | Value |
|------|-------|
| A | *It's cold in here* → literal temperature |
| B | *It's cold in here* → *Please close the window* |
| C | *It's cold in here* → *I like cold* |
| D | *It's cold in here* → *Turn on AC* |
**Key:** B
**br_pt_form:** "implicatura / significado implícito"

### Item 2 — Grammar (L1, adaptive)
Choose the **hedged** version:
| Slot | Value |
|------|-------|
| A | This *will* work. |
| B | This *might* work. |
| C | This *works*. |
| D | This *worked*. |
**Key:** B
**br_pt_form:** "Isso pode funcionar / atenuação."
