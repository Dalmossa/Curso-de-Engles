## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Collocation** refers to:
| Slot | Value |
|------|-------|
| A | Random word pairs |
| B | **Words that naturally go together (conduct research)** |
| C | Acronyms |
| D | Idioms only |
**Key:** B
**br_pt_form:** "colocação / palavras que vão juntas"

### Item 2 — Vocabulary (Matching)
Match the word family to its forms:
| Root | Forms |
|------|-------|
| **Decide** | a. decision, decisive, decisively |
| **Create** | b. creation, creative, creator |
| **Analyze** | c. analysis, analytical, analyst |
| **Manage** | d. management, manager, manageable |
**Key:** Decide→a, Create→b, Analyze→c, Manage→d
**br_pt_form:** "decidir", "criar", "analisar", "gerenciar"

### Item 3 — Grammar: Prefixes and suffixes (fill-in-blank)
Complete with correct **prefix/suffix**:
"______ (re) + do = redo. ______ (un) + happy = unhappy. ______ (teach) + ______ (-er) = teacher. ______ (happy) + ______ (-ness) = happiness."
**Key:** re / un / teach + er / happy + ness
**br_pt_form:** "re / infeliz / professor / felicidade"
