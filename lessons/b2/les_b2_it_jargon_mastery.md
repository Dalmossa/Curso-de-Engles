### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **jargon** | jargão | *vocabulário especializado de uma área* |
| **acronym** | sigla | *API, SDK, CI/CD* |
| **initialism** | inicialismo | *HTML, HTTP (letra por letra)* |
| **abbreviation** | abreviação | *Dr., approx.* |
| **collocation** | colocação | *make a decision, heavy rain* |
| **idiom** | idioma / expressão idiomática | *touch base, circle back* |
| **buzzword** | palavra da moda / buzzword | *synergy, disruption* |
| **euphemism** | eufemismo | *let go, downsize* |
| **technical term** | termo técnico | *latency, throughput* |
| **domain-specific** | específico do domínio | *bounded context, aggregate* |
| **plain language** | linguagem clara | *acessível a não-especialistas* |
| **glossary** | glossário | *lista de termos com definições* |

### Mini-texto (áudio: `deferred_render`)

> **Senior:** "**Jargon fluency** = know when to use and when to avoid. **Acronyms**: spell out first time. **Initialisms**: HTML, not H-T-M-L."
>
> "**Collocations**: *make* a decision (not *do*). *Heavy* rain (not *strong*). **Idioms**: *touch base* = quick sync. **Buzzwords**: *synergy* — use sparingly."
>
> "**Technical terms** for experts. **Plain language** for stakeholders. **Glossary** in docs. **Domain-specific** terms need context."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Collocation** refers to:
| Slot | Value |
|------|-------|
| A | Random word pairs |
| B | **Words that naturally go together (make a decision)** |
| C | Acronyms |
| D | Idioms only |
**Key:** B
**br_pt_form:** "colocação / palavras que vão juntas"

### Item 2 — Vocabulary (Matching)
Match the term type to its example:
| Type | Example |
|------|---------|
| **Acronym** | a. API (pronounced as word) |
| **Initialism** | b. HTML (letter by letter) |
| **Idiom** | c. touch base |
| **Buzzword** | d. synergy |
**Key:** Acronym→a, Initialism→b, Idiom→c, Buzzword→d
**br_pt_form:** "sigla", "inicialismo", "expressão idiomática", "palavra da moda"

### Item 3 — Grammar: Collocations (fill-in-blank)
Complete with correct **collocation**:
"______ (make/take) a decision. ______ (heavy/strong) rain. ______ (do/make) a mistake. ______ (fast/quick) food."
**Key:** Make / heavy / make / fast
**br_pt_form:** "tomar / forte / cometer / fast"

## FASE 3 — Output Task [4 min]

### Writing: Jargon Glossary (individual)
**Create a mini-glossary** for a non-technical stakeholder. Choose 10 terms from this lesson and define each in **plain language** (1 sentence).

**Example:**
- **API**: "A way for two systems to talk to each other, like a waiter taking your order to the kitchen."
- **Latency**: "How long it takes for a system to respond, like waiting for your food."

**Terms:** *jargon, acronym, initialism, idiom, buzzword, technical term, domain-specific, plain language, glossary, collocation*.
