## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **closing** | encerramento | *final da conversa* |
| **sign-off** | despedida / assinatura | *fechamento de e-mail ou reunião* |
| **wrap up** | encerrar / concluir | *finalizar* |
| **summary** | resumo | *síntese do que foi dito* |
| **action item** | item de ação | *tarefa acordada* |
| **next steps** | próximos passos | *o que fazer depois* |
| **follow up** | acompanhar | *retomar contato* |
| **thank you** | obrigado | *agradecimento* |
| **appreciate** | agradecer / valorizar | *reconhecer* |
| **look forward to** | aguardar com expectativa | *antecipar* |
| **best regards** | melhores cumprimentos | *despedida formal* |
| **sincerely** | sinceramente | *despedida formal* |
| **take care** | cuide-se | *despedida informal* |

### Mini-texto (áudio: `deferred_render`)

> A: Let's **wrap up**. **Summary**: we agreed on the budget and timeline.
> B: **Next steps**: I'll send the proposal by Friday.
> A: Great. I'll **follow up** with the client.
> B: **Thank you** for your time. I **look forward to** working together.
> A: **Best regards**!
> B: **Take care**!

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Wrap up** means:
| Slot | Value |
|------|-------|
| A | Start a meeting |
| B | **End / conclude** |
| C | Postpone |
| D | Cancel |
**Key:** B
**br_pt_form:** "encerrar / concluir"

### Item 2 — Vocabulary (Matching)
Match the sign-off to its formality:
| Sign-off | Formality |
|----------|-----------|
| **Best regards** | a. Formal |
| **Sincerely** | b. Very formal |
| **Take care** | c. Informal |
| **Thanks** | d. Neutral |
**Key:** Best regards→a, Sincerely→b, Take care→c, Thanks→d
**br_pt_form:** "melhores cumprimentos", "sinceramente", "cuide-se", "obrigado"

### Item 3 — Grammar: Future with will for next steps (fill-in-blank)
Complete with **will + verb**:
"I ______ (send) the proposal. She ______ (follow up). They ______ (review) the contract."
**Key:** will send / will follow up / will review
**br_pt_form:** "enviarei / fará follow-up / revisarão"

## FASE 3 — Output Task [4 min]

### Speaking: Meeting Wrap-up (pares)
**Scenario**: End a meeting professionally.

**Structure:**
1. **Wrap up** (let's wrap up)
2. **Summary** (we agreed on...)
3. **Action items** (I'll..., She'll...)
4. **Next steps** (next meeting is...)
5. **Sign-off** (best regards, take care)

**Create a 6-line closing dialogue**.
