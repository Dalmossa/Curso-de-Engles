### Vocabulário-chave (com gloss PT-BR)

| **corporate speak** | linguagem corporativa | *jargão de negócios* |

| **CFO** | CFO | *Chief Financial Officer* |

| **EOD** | EOD | *End Of Day* |

| **synergy** | sinergia | *bônus da combinação* |

### Mini-texto (áudio: `deferred_render`)

> "A: The **CEO** wants the **KPI** report by **EOD**."
> B: Sure. I'll send it **ASAP**. **FYI**, the **CFO** is **OOO** today."
> A: OK. What's the **ROI** on this project?
> B: We expect 20% **ROI**. The **synergy** between teams is great."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**ASAP** stands for:
| Slot | Value |
|------|-------|
| A | As Soon As Possible |
| B | **As Soon As Possible** |
| C | Always Start A Project |
| D | All Systems Are Perfect |
**Key:** B
**br_pt_form:** "o mais rápido possível"

### Item 2 — Vocabulary (Matching)
Match the acronym to its meaning:
| Acronym | Meaning |
|---------|---------|
| **CEO** | a. Chief Executive Officer |
| **HR** | b. Human Resources |
| **ROI** | c. Return On Investment |
| **EOD** | d. End Of Day |
**Key:** CEO→a, HR→b, ROI→c, EOD→d
**br_pt_form:** "CEO", "RH", "ROI", "fim do dia"

### Item 3 — Grammar: Present simple for corporate facts (fill-in-blank)
Complete with **present simple**:
"The ______ (CEO/lead) the company. The ______ (CFO/manage) finances. ______ (HR/handle) hiring."
**Key:** CEO leads / CFO manages / HR handles
**br_pt_form:** "CEO lidera / CFO gerencia / RH cuida"

## FASE 3 — Output Task [4 min]

### Speaking: Corporate Meeting (pares)
**Scenario**: Use corporate acronyms in a meeting.

**Create a dialogue** using at least 8 acronyms: CEO, CFO, HR, KPI, ROI, ASAP, FYI, EOD, OOO, synergy.

**Example:**
> A: "The CEO wants the KPI report by EOD."
> B: "I'll send it ASAP. FYI, the CFO is OOO."
> A: "What's the ROI?"
> B: "20%. The synergy is great."
