## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **phone call** | ligação / chamada | *conversa por telefone* |
| **video call** | chamada de vídeo | *conversa com câmera* |
| **dial** | discar | *fazer ligação* |
| **answer** | atender | *responder chamada* |
| **hang up** | desligar | *encerrar chamada* |
| **hold on** | espere / aguarde | *pedir para esperar* |
| **speak up** | falar mais alto | *aumentar volume* |
| **cut off** | cair / ser cortado | *chamada interrompida* |
| **voicemail** | correio de voz | *mensagem gravada* |
| **callback** | retorno | *ligar de volta* |
| **mute** | silenciar | *desligar microfone* |
| **speakerphone** | viva-voz | *alto-falante* |

### Mini-texto (áudio: `deferred_render`)

> "A: **Hello**, this is Ana. Can I speak with John?"
> B: "Sure, **hold on** please."
> A: "Hi John, I'm **calling** about the meeting."
> B: "Sorry, you're breaking up. Can you **speak up**?"
> A: "Sure. Let me **call you back**."
> B: "OK. **Talk to you later**."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Hold on** means:
| Slot | Value |
|------|-------|
| A | Hang up |
| B | **Wait / hold the line** |
| C | Speak louder |
| D | Call back |
**Key:** B
**br_pt_form:** "espere / aguarde na linha"

### Item 2 — Vocabulary (Matching)
Match the call phrase to its use:
| Phrase | Use |
|--------|-----|
| **Answer** | a. Pick up the phone |
| **Hang up** | b. End the call |
| **Hold on** | c. Wait a moment |
| **Speak up** | d. Talk louder |
**Key:** Answer→a, Hang up→b, Hold on→c, Speak up→d
**br_pt_form:** "atender", "desligar", "aguardar", "falar mais alto"

### Item 3 — Grammar: Present continuous for calls (fill-in-blank)
Complete with **present continuous**:
"I ______ (call) you. She ______ (talk) to the client. They ______ (wait) for the manager."
**Key:** am calling / is talking / are waiting
**br_pt_form:** "estou ligando / está falando / estão esperando"

## FASE 3 — Output Task [4 min]

### Speaking: Phone Call Roleplay (pares)
**Scenario**: You call a colleague to reschedule a meeting.

**Useful phrases:**
- Hello, this is...
- Can I speak with...?
- Hold on, please.
- I'm calling about...
- Can we reschedule?
- Talk to you later.

**Create a 6-line dialogue** using the vocabulary.
