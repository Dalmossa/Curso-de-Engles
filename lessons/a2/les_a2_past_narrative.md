## FASE 1 — Input Contextualizado (i+1) [4 min]

### Cenário: a retro de uma sexta com incidente de pagamento

> **Bruno (SRE):** "Let's start the retro. First, what happened on Friday at 14:00?"
>
> **Ana (backend developer):** "The deploy went out, and I saw an error in the payment log."
>
> **Caio (QA):** "I found the same error in staging. We told the team in the incident channel."
>
> **Lu (frontend developer):** "I took a screenshot of the screen and sent it to Bruno."
>
> **Bruno:** "Good. Ana wrote the timeline, and Caio ran the test again."
>
> **Ana:** "We fixed the bug at 15:20, and we learned one thing: we need a better check before deploy."

### Glossário contrastivo (pt-BR ↔ en-US)

| Inglês (en-US) | Português (pt-BR) | Nota de uso prático |
|---|---|---|
| **The deploy went out** | O deploy saiu / foi para produção | *Went* é o passado irregular de *go*; não existe *goed*. |
| **I saw an error** | Eu vi um erro | *Saw* é o passado de *see*; *seed* é um substantivo ("semente"). |
| **We found the same error** | Encontramos o mesmo erro | *Found* é o passado de *find*, e fecha a sequência dos fatos. |
| **We told the team** | Avisamos o time | *Tell* recebe a pessoa direto: *told the team*, sem *to*. |
| **I took a screenshot** | Tirei um print | Em en-US, *screenshot* é a palavra natural; *took* é o passado de *take*. |
| **I sent it to Bruno** | Enviei para o Bruno | Quando a coisa vem primeiro, use *to* antes da pessoa. |
| **Ana wrote the timeline** | A Ana escreveu a linha do tempo | *Wrote* é o passado de *write*; *timeline* é o registro ordenado dos fatos. |
| **We learned one thing** | Aprendemos uma coisa | Em en-US prefira *learned*; *learnt* soa britânico. |

### Tabela de armadilhas comuns (falantes de pt-BR)

| Armadilha (pt-BR → forma inadequada) | Forma natural em en-US | Por quê? |
|---|---|---|
| "We **runned** the test again." | "We **ran** the test again." | *Run* é irregular: a forma passada é **ran**, não *runned*. |
| "I **seed** an error in the log." | "I **saw** an error in the log." | O passado de *see* é **saw**; aplicar a regra do *-ed* cria uma palavra que não existe. |
| "We **told to** the team." | "We **told** the team." | O pt-BR diz "avisar **para** o time"; em inglês, *tell* já leva a pessoa sem preposição. |
| "We fixed the bug **in Friday**." | "We fixed the bug **on Friday**." | Dias da semana pedem **on**; *in* fica para meses e anos. |
| "The bug **is** in the log yesterday." | "The bug **was** in the log yesterday." | Uma marca explícita de tempo passado como *yesterday* pede o passado de *be*. |

## FASE 2 — Prática Guiada [5 min]

### Exercício 1 — Reconhecimento (L1)

Qual frase conta corretamente o que aconteceu na sexta?

| Opção | Frase |
|---|---|
| A | "Last Friday we finded the root cause and told the team." |
| B | **"Last Friday we found the root cause and told the team."** |
| C | "Last Friday we find the root cause and tell the team." |
| D | "Last Friday we are finding the root cause and telling the team." |

**Key:** B
*Found* e *told* são formas irregulares no passado e carregam a sequência da narrativa. *Finded* não existe, o presente em C ignora *last Friday*, e D mistura progressivo com um evento já encerrado.

### Exercício 2 — Transformação L1 → L2

Reescreva as intenções em inglês natural, mantendo o passado:

| Português (intenção) | Resposta esperada |
|---|---|
| "Na sexta, o deploy foi para produção." | "On Friday, the deploy went out." |
| "Eu vi um erro no log." | "I saw an error in the log." |
| "Nós avisamos o time no canal." | "We told the team in the channel." |
| "O Caio rodou o teste de novo." | "Caio ran the test again." |

**Key:** went / saw / told / ran
Cada intenção pede uma forma irregular: *go→went*, *see→saw*, *tell→told*, *run→ran*. Decoramos essas formas como palavras inteiras, não como *-ed* acrescentado.

### Exercício 3 — Contraste de forma: passado simples, passado contínuo e presente

Complete as lacunas observando o papel de cada tempo:

1. "At 14:00 on Friday, we ______ (run) the deploy." → **ran**
2. "While the deploy ______ (run), Ana watched the logs." → **was running**
3. "Every Friday we ______ (write) a timeline; last Friday we ______ (write) it in ten minutes." → **write / wrote**

**Key:** 1) ran; 2) was running; 3) write / wrote.
O passado simples avança a história com fatos concluídos; o passado contínuo (*was running*) descreve a ação de fundo que estava em andamento; o presente simples fica para a rotina (*every Friday*).

## FASE 3 — Tarefa de Produção (Output & Pronúncia) [4 min]

### 5 sentenças-alvo (leia em voz corrida)

On Friday the deploy went out at two, and I saw an error in the payment log. Caio found the same error in staging and told the team in the incident channel. Lu took a screenshot and sent it to Bruno before the retro started. Ana wrote the timeline while the tests were running, and then we ran the suite again. We fixed the bug at 15:20 and learned that we need a better check before every deploy.

### Foco articulatório para falantes de pt-BR

- **-ed final /t/ em *fixed*** /fɪkst/: depois de /k/, a terminação soa como /t/ sem acrescentar sílaba; não diga "fi-xêd".
- **-ed final /d/ em *learned*** /lɜːrnd/: depois de /n/, a terminação soa como /d/, também sem sílaba extra.
- **-ed final /ɪd/ em *started*** /stɑːrtɪd/: só depois de /t/ e /d/ a terminação ganha sílaba própria /ɪd/.
- **Irregulares não recebem -ed**: *went* /went/, *saw* /sɔː/, *told* /toʊld/, *ran* /ræn/ são palavras memorizadas; *runned* e *seed* não existem.
- **/ð/ em *the, then***: ponta da língua entre os dentes com voz; evite trocar por /d/ ("de").
- **Ritmo da narrativa**: una *went out* e *told the* em bloco único, sem inserir vogal entre a consoante final e a palavra seguinte.

### Prompt de produção (oral ou escrita)

Imagine que você abre a retro de uma sexta com um incidente de pagamento. Escreva ou diga um parágrafo curto de **5 a 7 frases** em que você: (1) situa o dia com **on Friday**; (2) usa pelo menos **três verbos irregulares no passado** (*go→went, see→saw, find→found, tell→told, take→took, run→ran, write→wrote*); (3) usa o **passado contínuo** para uma ação de fundo com *while*; (4) termina com o que o time **learned**; (5) inclui um detalhe do seu contexto (deploy, ticket, log, stand-up).

## FASE 4 — Shadow CAT / Verificação Rápida [2 min]

1. **Gramática (L1):** Qual frase encerra corretamente a narrativa da retro?  
   A) "Last Friday we run the test again."  B) **"Last Friday we ran the test again."**  C) "Last Friday we are running the test again."  D) "Last Friday we runned the test again."  
   **Key:** B
   *Last Friday* exige o passado simples, e a forma irregular de *run* é *ran*; *runned* não existe.

2. **Vocabulário (L1):** O que diz a frase "Lu took a screenshot and sent it to Bruno"?  
   A) "A Lu ligou para o Bruno."  B) "A Lu apagou a imagem."  C) **"A Lu tirou um print e enviou ao Bruno."**  D) "A Lu escreveu a linha do tempo."  
   **Key:** C
   *Took a screenshot* = "tirou um print"; *sent it to Bruno* = "enviou ao Bruno". A linha do tempo foi escrita pela Ana.

3. **Leitura (L1):** Ao ler rapidamente "We fixed the bug at 15:20 and learned that we need a better check before deploy", qual é o resultado informado?  
   A) "O deploy saiu às 14h."  B) **"O bug foi corrigido às 15h20."**  C) "O time escreveu a linha do tempo."  D) "O teste falhou."  
   **Key:** B
   O resultado literal é *fixed the bug at 15:20*; as demais opções trazem detalhes de outras frases ou informações ausentes.
