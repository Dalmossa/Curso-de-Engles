## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **imperative** | imperativo | *ordem, instrução* |
| **base verb** | verbo base | *sem to, sem -s* |
| **Open the door** | abra a porta | *instrução direta* |
| **Don't touch** | não toque | *proibição* |
| **Press the button** | aperte o botão | *instrução* |
| **Turn left** | vire à esquerda | *direção* |
| **Wait here** | espere aqui | *instrução* |
| **Be careful** | tenha cuidado | *aviso* |
| **Make sure** | certifique-se | *verificação* |
| **follow** | seguir | *obedecer instruções* |
| **step** | passo | *etapa de procedimento* |
| **procedure** | procedimento | *sequência de passos* |
| **instruction** | instrução | *direção a seguir* |

### Mini-texto (áudio: `deferred_render`)

> "**Imperatives** give instructions: '**Open** the file.' '**Click** the button.' '**Don't forget** to save.'"
>
> "**Negative imperatives**: '**Don't touch** that.' '**Don't be** late.' '**Never share** passwords.'"
>
> "**Procedures**: '**First**, log in. **Then**, open the app. **Finally**, check the settings.'"

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Imperative** form uses:
| Slot | Value |
|------|-------|
| A | To + verb |
| B | **Base verb (no to)** |
| C | -ing form |
| D | -ed form |
**Key:** B
**br_pt_form:** "imperativo / verbo base (sem to)"

### Item 2 — Vocabulary (Matching)
Match the imperative to its use:
| Imperative | Use |
|------------|-----|
| **Open the door** | a. Instruction |
| **Don't touch** | b. Prohibition |
| **Be careful** | c. Warning |
| **Wait here** | d. Direction |
**Key:** Open the door→a, Don't touch→b, Be careful→c, Wait here→d
**br_pt_form:** "abra a porta", "não toque", "tenha cuidado", "espere aqui"

### Item 3 — Grammar: Imperative form (fill-in-blank)
Complete with **imperative**:
"______ (open) the door. ______ (not/touch) that. ______ (be) careful. ______ (wait) here."
**Key:** Open / Don't touch / Be / Wait
**br_pt_form:** "Abra / Não toque / Tenha / Espere"

## FASE 3 — Output Task [4 min]

### Speaking: Procedure Explanation (individual)
**Explain a procedure** using imperatives + sequence markers.

**Example (How to reset a password):**
> "**First**, go to settings. **Then**, click 'Forgot password'. **After that**, enter your email. **Finally**, check your inbox. **Don't forget** to create a strong password."

**Create your own procedure** with 5 steps.
