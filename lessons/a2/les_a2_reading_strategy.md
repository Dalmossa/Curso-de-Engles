## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **skim** | skimming / leitura rápida | *ideia geral* |
| **scan** | scanning / leitura direcionada | *informação específica* |
| **context** | contexto | *situação do texto* |
| **cognate** | cognato | *palavra similar em PT e EN* |
| **false cognate** | falso cognato | *parece igual, significa outro* |
| **main idea** | ideia principal | *ponto central* |
| **detail** | detalhe | *informação específica* |
| **infer** | inferir | *concluir além do explícito* |
| **predict** | prever | *antecipar* |
| **summarize** | resumir | *sintetizar* |
| **paragraph** | parágrafo | *bloco de texto* |
| **topic sentence** | frase-tópico | *frase principal do parágrafo* |

### Mini-texto (áudio: `deferred_render`)

> "**Skimming**: read quickly for **main idea**. **Scanning**: read for specific **details**."
>
> "**Context** helps **infer** meaning. **Cognates** help, but watch **false cognates**."
>
> "**Topic sentence** is usually the first sentence of a **paragraph**. **Summarize** in your own words."

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Cognates** are:
| Slot | Value |
|------|-------|
| A | Words that look different |
| B | **Words similar in Portuguese and English** |
| C | Words with no meaning |
| D | Only false friends |
**Key:** B
**br_pt_form:** "cognatos / palavras similares em PT e EN"

### Item 2 — Vocabulary (Matching)
Match the reading strategy to its purpose:
| Strategy | Purpose |
|----------|---------|
| **Skim** | a. Main idea |
| **Scan** | b. Specific details |
| **Infer** | c. Read between lines |
| **Predict** | d. Anticipate content |
**Key:** Skim→a, Scan→b, Infer→c, Predict→d
**br_pt_form:** "skimming", "scanning", "inferir", "prever"

### Item 3 — Grammar: Imperatives for reading strategies (fill-in-blank)
Complete with **imperative**:
"______ (skim) for main idea. ______ (scan) for details. ______ (infer) from context. ______ (summarize) in your own words."
**Key:** Skim / Scan / Infer / Summarize
**br_pt_form:** "Faça skimming / Faça scanning / Inferir / Resuma"

## FASE 3 — Output Task [4 min]

### Reading: Strategy Practice (individual)
**Read this short text:**

> "Remote work is becoming more common. Many companies now offer flexible hours. Employees can work from home or the office. This improves work-life balance."

**Tasks:**
1. **Skim**: Main idea? (1 sentence)
2. **Scan**: Where can employees work?
3. **Infer**: Why is remote work becoming common?
4. **Summarize**: In your own words (2 sentences)
