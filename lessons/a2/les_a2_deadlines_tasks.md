## FASE 1 — Input (i+1) [4 min]

### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **deadline** | prazo | *data limite* |
| **task** | tarefa | *unidade de trabalho* |
| **follow-up** | acompanhamento | *retomar contato* |
| **assign** | atribuir / designar | *dar tarefa a alguém* |
| **complete** | concluir / completar | *finalizar* |
| **submit** | enviar / submeter | *entregar formalmente* |
| **review** | revisar | *analisar* |
| **approve** | aprovar | *dar aval* |
| **pending** | pendente | *não concluído* |
| **overdue** | atrasado / vencido | *passou do prazo* |
| **priority** | prioridade | *ordem de importância* |
| **status** | status / situação | *estado atual* |

### Mini-texto (áudio: `deferred_render`)

> A: What's the **status** of the report?
> B: It's **pending** review. The **deadline** is Friday.
> A: Can you **complete** it by Thursday?
> B: Yes, I'll **submit** it for **review** tomorrow.
> A: Good. I'll **follow up** with the client.
> B: Thanks. It's a high **priority** task.

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Overdue** means:
| Slot | Value |
|------|-------|
| A | Completed early |
| B | **Past the deadline** |
| C | Not started |
| D | Low priority |
**Key:** B
**br_pt_form:** "atrasado / vencido / passou do prazo"

### Item 2 — Vocabulary (Matching)
Match the task stage to its description:
| Stage | Description |
|-------|-------------|
| **Assign** | a. Give task to someone |
| **Complete** | b. Finish |
| **Submit** | c. Send for review |
| **Approve** | d. Give approval |
**Key:** Assign→a, Complete→b, Submit→c, Approve→d
**br_pt_form:** "atribuir", "concluir", "enviar", "aprovar"

### Item 3 — Grammar: Future with will for commitments (fill-in-blank)
Complete with **will + verb**:
"I ______ (submit) the report tomorrow. She ______ (complete) the task. They ______ (follow up) with the client."
**Key:** will submit / will complete / will follow up
**br_pt_form:** "enviarei / concluirá / farão follow-up"

## FASE 3 — Output Task [4 min]

### Speaking: Task Delegation (pares)
**Scenario**: You are the manager. Delegate tasks to your team.

**Useful phrases:**
- Can you take care of...?
- The deadline is...
- Please submit... by...
- I'll follow up with...
- What's the status?

**Create a dialogue** delegating 3 tasks with deadlines.

### Item 1 — Vocabulary (L1, adaptive)

| Slot | Value |
|------|-------|
| A | Completed |
| B | **Not yet completed / waiting** |
| C | Overdue |
| D | Cancelled |
**Key:** B
**br_pt_form:** "pendente / não concluído / aguardando"

### Item 2 — Grammar (L1, adaptive)
Choose the correct **future with will**:
| Slot | Value |
|------|-------|
| A | I **submit** the report tomorrow. |
| B | I **will submit** the report tomorrow. |
| C | I **submitting** the report tomorrow. |
| D | I **submitted** the report tomorrow. |
**Key:** B
**br_pt_form:** "Enviarei o relatório amanhã."
