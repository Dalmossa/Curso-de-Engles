### Vocabulário-chave (com gloss PT-BR)

| English | PT-BR | Contexto |
|---------|-------|----------|
| **modal verb** | verbo modal | *can, need, should* |
| **can** | poder / conseguir | *habilidade, permissão* |
| **need** | precisar | *necessidade* |
| **should** | deveria | *conselhos, recomendações* |
| **ability** | habilidade | *capacidade* |
| **permission** | permissão | *autorização* |
| **necessity** | necessidade | *algo necessário* |
| **advice** | conselho | *recomendação* |

| **possibility** | possibilidade | *algo possível* |
| **request** | pedido | *solicitação* |
| **suggestion** | sugestão | *ideia para considerar* |
| **must** | deve / tem que | *obrigação forte* |

### Mini-texto (áudio: `deferred_render`)

> "**Can**: ability and permission. 'I **can** speak English.' '**Can** I leave early?'"
>
> "**Need**: necessity. 'I **need** to finish this.' 'Do you **need** help?'"
>
> "**Should**: advice. 'You **should** rest.' 'We **should** start the meeting.'"
>
> "**Must**: strong obligation. 'You **must** wear a helmet.'"

## FASE 2 — Guided Practice [5 min]

### Item 1 — Vocabulary (MCQ)
**Should** is used for:
| Slot | Value |
|------|-------|
| A | Ability |
| B | **Advice / recommendation** |
| C | Necessity |
| D | Permission |
**Key:** B
**br_pt_form:** "should / conselho / recomendação"

### Item 2 — Vocabulary (Matching)
Match the modal to its function:
| Modal | Function |
|-------|----------|
| **Can** | a. Ability / permission |
| **Need** | b. Necessity |
| **Should** | c. Advice |
| **Must** | d. Strong obligation |
**Key:** Can→a, Need→b, Should→c, Must→d
**br_pt_form:** "can", "need", "should", "must"

### Item 3 — Grammar: Modal + base verb (fill-in-blank)
Complete with **modal + base verb**:
"I ______ (can/speak) English. She ______ (need/finish) this. They ______ (should/rest)."
**Key:** can speak / need to finish / should rest
**br_pt_form:** "posso falar / precisa terminar / deveriam descansar"

## FASE 3 — Output Task [4 min]

### Speaking: Advice Column (pares)
**Give advice** using should/can/need.

**Scenarios:**
1. A colleague is tired. (You should rest.)
2. A colleague wants to learn English. (You can practice daily.)
3. A colleague has too much work. (You need to prioritize.)

**Create 6 advice sentences** using can, need, should.
