## FASE 1 — Input Contextualizado (i+1) [4 min]

### Cenário: stand-up diário de um time de engenharia

> **Rafa (tech lead):** "Morning, everyone. Let's keep the stand-up short. Ana, what did you ship yesterday?"
>
> **Ana (backend developer):** "I shipped the fix for the login ticket. I sent the API change to staging last night, and it is live now."
>
> **Rafa:** "Nice. Bruno, before we go on — are you a developer on this squad?"
>
> **Bruno (QA engineer):** "Actually, I'm a QA engineer. I found a bug in the checkout flow, and eventually I'll write the test for it."
>
> **Ana:** "Can you put that in the document? Our documentation is still thin."
>
> **Bruno:** "Sure. One document for the bug, one line in the docs. Is *hotfix* the term we use for this kind of fix?"
>
> **Rafa:** "Yes — *hotfix* is the team term. Let's ship the docs with the release. See you all at the retro."

### Glossário contrastivo (pt-BR ↔ en-US)

| Inglês (en-US) | Português (pt-BR) | Nota de uso prático |
|---|---|---|
| **term** | termo técnico | Uma etiqueta com sentido definido (*hotfix*, *code review*). Não é a palavra comum do dia a dia. |
| **word** | palavra | Qualquer sequência de letras com sentido. Use *term* quando o time combina um nome técnico. |
| **document** | um documento | Substantivo contável: *a document*, *two documents*. Um arquivo, uma página, um ticket. |
| **documentation** | documentação | Substantivo não contável: sem artigo e sem plural. O conjunto de docs do projeto. |
| **to ship** | entregar / publicar | Colocar uma mudança no ar para os usuários: *we shipped the fix*. |
| **to send** | enviar | Levar uma mensagem, um link ou um arquivo até alguém: *I sent you the link*. |
| **actually** | na verdade / de fato | Corrige uma crença. **Não** significa *atualmente*. |
| **eventually** | no fim / mais tarde | Marca um momento futuro. **Não** é o *eventualmente* de "talvez, se precisar". |
| **a QA engineer** | um engenheiro QA | Título de função pede artigo quando descrevemos alguém: *a/an + role*. |
| **the tech lead** | o tech lead | Artigo definido quando existe uma pessoa específica na equipe. |
| **code review** | revisão de código | Composto: o modificador vem primeiro e o plural cai na cabeça — *code reviews*. |

### Tabela de armadilhas comuns (falantes de pt-BR)

| Armadilha (pt-BR → forma inadequada) | Forma natural em en-US | Por quê? |
|---|---|---|
| "I wrote **a documentation** for the endpoint." | "I wrote **documentation** for the endpoint." | *Documentation* é não contável: não leva *a* e não vira *documentations*. Para um arquivo só, use *a document*. |
| "I **sent** the fix to production." (querendo dizer *subimos*) | "I **shipped** the fix to production." | *Ship* é liberar a mudança para os usuários; *send* é enviar algo a alguém. |
| "I **shipped** you the link." (querendo dizer *enviei*) | "I **sent** you the link." | O link é uma mensagem/arquivo, não uma release. |
| "**Actually** we are on vacation." (querendo dizer *atualmente*) | "**Currently** we are on vacation." | *Actually* corrige uma ideia; o tempo presente é *currently* / *nowadays*. |
| "We will write the guide **actually**." (querendo dizer *eventualmente/no fim*) | "We will write the guide **eventually**." | *Eventually* aponta para um momento posterior; *actually* não fala de tempo. |
| "Bruno is **QA engineer** on this squad." | "Bruno is **a QA engineer** on this squad." | Em pt-BR o artigo some antes do cargo; em inglês ele aparece: *a QA engineer*. |
| "We closed the **review of code**." | "We closed the **code review**." | O termo técnico é um composto sem preposição: modificador primeiro, cabeça depois. |
| "Do you know this **term**?" (falando de uma palavra comum) | "Do you know this **word**?" | *Term* reserva-se a rótulos técnicos definidos pelo time. |

## FASE 2 — Prática Guiada [5 min]

### Exercício 1 — Docs: um arquivo ou o conjunto?

Você escreveu uma página nova e a colocou na wiki do time. Escolha a frase natural.

| Opção | Frase |
|---|---|
| A | "I wrote a documentation and added a documentations to the wiki." |
| B | **"I wrote documentation and added a document to the wiki."** |
| C | "I wrote a documentation and added a document to the wiki." |
| D | "I wrote documentations and added a documentation to the wiki." |

**Key:** B

### Exercício 2 — Ship ou send?

Ana liberou a correção para os usuários e depois mandou o link do ticket ao Bruno.

| Intenção (pt-BR) | Resposta esperada |
|---|---|
| "Ana enviou o link ao Bruno." | "Ana sent Bruno the ticket link." |
| "Ana entregou a correção em produção." | "Ana shipped the fix to production." |
| "Ana enviou a correção para produção." (forma inadequada) | "Ana shipped the fix to production." |
| "Ana entregou o link ao Bruno." (forma inadequada) | "Ana sent Bruno the link." |

**Key:** sent / shipped / shipped / sent

### Exercício 3 — Actually, eventually e o artigo do cargo

Complete as lacunas com **actually**, **eventually** ou **a / an / the**:

1. "___ I'm a QA engineer, not a developer." → **Actually**
2. "We'll write the guide ___ , after the demo." → **eventually**
3. "She is ___ tech lead of the platform team." → **the**

**Key:** 1) Actually; 2) eventually; 3) the.

## FASE 3 — Tarefa de Produção (Output & Pronúncia) [4 min]

### 5 sentenças-alvo (leia em voz corrida)

Actually I'm a QA engineer, and I write a document for every ticket.
We shipped the fix last night and sent the link to the team.
Our documentation is short, so Ana writes a new document today.
Eventually the tech lead will review the code and close the release window.
Is that the term we use for a root cause, or do we call it a bug?

### Foco articulatório para falantes de pt-BR

- **Cluster /st/ em *stack*:** comece com /s/ e encoste o /t/ sem inserir vogal; evite "istack".
- **Final /ks/ em *docs*:** mantenha /k/ e /s/ na mesma sílaba, sem acrescentar um "e" final.
- **TH voiced /ð/ em *that*:** língua entre os dentes com voz; não troque por /dʒ/ ("dád") nem por /z/.
- **Actually /ˈæktʃuəli/:** marque as três sílabas com o /tʃ/ central; não reduza a uma sílaba só.
- **Ritmo do composto:** em *code review* e *root cause*, o modificador fica curto e a cabeça recebe o acento.

### Prompt de produção (oral ou escrita)

Imagine que você entra na daily de um time novo e precisa contar o que fez ontem. Crie **4 a 6 falas** em que você: usa **ship** para uma mudança que subiu, usa **send** para um link ou arquivo, diz seu cargo com artigo, corrige uma suposição com **actually**, fala de uma tarefa futura com **eventually** e usa pelo menos **um termo técnico** do time (*hotfix*, *code review*, *root cause*). Se puder, inclua um detalhe real da sua rotina (sprint, ticket, deploy, plantão).

   A) "Bruno is QA engineer on this squad."  B) "Bruno is an QA engineer on this squad."  C) **"Bruno is a QA engineer on this squad."**  D) "Bruno is a QA engineers on this squad."
   **Key:** C

2. **Vocabulário (L1):** Qual frase usa *actually* e *eventually* com o sentido certo?
   A) "Eventually he is a QA engineer; actually we'll add the guide."  B) "Actually he is a QA engineer; actually we'll add the guide."  C) **"Actually he is a QA engineer; eventually we'll add the guide."**  D) "Eventually he is a QA engineer; eventually we'll add the guide."
   **Key:** C
